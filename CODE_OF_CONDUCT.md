# Code of Conduct

## Our commitment

Everyone participating in this project should feel welcome and safe. Treat other people with respect, assume good intent, and give constructive feedback focused on the work.

## Expected behavior

- Be considerate and professional in issues, pull requests, reviews, and other project discussions.
- Welcome different experience levels and points of view.
- Accept feedback gracefully and help resolve disagreements constructively.

Harassment, discrimination, personal attacks, threats, and sharing someone else's private information without permission are not acceptable.

## Scope and enforcement

This code applies to all project spaces and to public interactions where someone represents the project. The maintainer may remove comments, close contributions, or restrict participation when this code is violated.

Report concerns privately to [saulotarsobc+electronvite@gmail.com](mailto:saulotarsobc+electronvite@gmail.com). Include relevant links or context if you can. Reports will be reviewed discreetly; information will be shared only as needed to address the concern.
