# Security Policy

## Supported versions

Security fixes are considered for the latest published release. Older releases are not maintained separately.

## Reporting a vulnerability

Please email [saulotarsobc+electronvite@gmail.com](mailto:saulotarsobc+electronvite@gmail.com) with the subject `Security report: sc-electron-boilerplate`. Do not open a public issue or pull request for an undisclosed vulnerability.

Include the affected version, steps to reproduce, the possible impact, and a proof of concept if available. Please avoid including real user data or secrets. The maintainer will review the report and coordinate disclosure and a fix with you. Do not publish details until there has been an opportunity to address the issue.
